  高校学生管理系统  使用说明
════════════════════════════════════════════════════════════

一、启动（无需安装任何环境）
──────────────────────────────────────────────
  Windows：双击「启动服务.bat」
  macOS / Linux：在终端执行 ./start.sh

  首次启动会自动创建数据库并写入演示数据（约 1000 名学生、
  5900 条选课成绩、14 篇官网文章），随后浏览器会自动打开官网首页。

  运行期间请勿关闭那个黑色命令行窗口，关闭窗口即停止服务。

  ● 本包已内置 Node 运行时，目标电脑无需安装 Node.js 或任何数据库。
  ● 万一 node 目录被删除，启动脚本会自动联网下载补齐。


二、访问地址
──────────────────────────────────────────────
  学校官网    http://localhost:8000/
  管理后台    http://localhost:8000/admin
  接口索引    http://localhost:8000/api

四、常用配置
──────────────────────────────────────────────
  用记事本打开本目录下的 .env 文件即可修改：

  PORT=8000            服务端口。若提示端口被占用，改成 8080 等其它端口，
                       之后访问地址相应变成 http://localhost:8080/
  JWT_SECRET=...       登录令牌密钥，正式使用时请改成自己的随机字符串
  OPEN_BROWSER=true    启动后是否自动打开浏览器，改为 false 则不自动打开


五、数据与备份
──────────────────────────────────────────────
  所有数据都在 data/school-erp.db 这一个文件里：

  备份   直接复制 data 目录即可
  迁移   把 data 目录随程序一起拷到新机器
  重置   删除 data 目录后重启，会自动重新生成演示数据
  清库   只想清空业务数据但保留结构，可执行
         node\node.exe server\dist\server.js 前先删除 data\school-erp.db


六、常见问题
──────────────────────────────────────────────
  1) 双击后窗口一闪而过
     多为端口被占用。请用记事本打开 .env，把 PORT 改成 8080 后重试；
     或查看窗口中的错误提示。

  2) 浏览器没有自动打开
     手动在浏览器输入 http://localhost:8000/ 即可。

  3) 局域网内其它电脑访问
     用本机 IP 替换 localhost，例如 http://192.168.1.10:8000/
     如仍无法访问，请检查 Windows 防火墙是否放行该端口。

  4) 提示 node 不是可用的程序 / 下载运行时失败
     说明网络受限。可手动到 https://nodejs.org/zh-cn/download 下载
     Node.js 22 以上版本的 Windows 安装包，安装后重新双击启动脚本。


七、卸载
──────────────────────────────────────────────
  直接删除整个文件夹即可，不会在系统里留下任何残留
  （不写注册表、不装服务、不改环境变量）。
